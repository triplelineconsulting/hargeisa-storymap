# Hargeisa Flood Risk — Story Map (Draft)

Built on the same template and Triple Line brand as the Mogadishu story map.

## Live layers
- Flood depth bands for six return periods (T2, T5, T10, T25, T50, T100) — revealed
  as a scroll-through progression on the flood-hazard chapters.
- Building morphology (HousingTypeSM) — formal residential, informally-built, IDP,
  and non-residential/mixed use — revealed category-by-category as the reader scrolls.
- Survey target areas, key infrastructure (by type), and the projected 2050 urban extent.
